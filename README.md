# Resto client template

Blueprint Next.js (App Router) pour restaurants / pizzerias — one-page conversion (carte, horaires, téléphone, légal).

- **Stack** : Next.js 16, Tailwind CSS 4, Framer Motion, Lucide
- **Personnalisation** : `config/site.ts`, `config/theme.ts`, fichiers `data/*`, images `IMGS/`

Documentation détaillée : [`docs/CONFIG-CLIENT.md`](docs/CONFIG-CLIENT.md).

```bash
npm install
npm run dev
```

Build production : `npm run build`.
